# ppics

Member Management System

## Project Overview

This is a comprehensive member management application built with a full-stack architecture.

## Project Structure

- **backend/** - Node.js/Express backend API
- **backend-python/** - Python backend service
- **frontend/** - Web frontend
- **frontend_flutter/** - Flutter mobile app
- **mobile/** - Native mobile app
- **app/** - Additional app resources

## Technologies

- **Backend:** Node.js, Express, Python
- **Frontend:** JavaScript/React
- **Mobile:** Flutter, Native Android
- **Database:** Docker Compose setup
- **Build:** Gradle (Kotlin)

## Getting Started

See `walkthrough.md` for detailed setup and walkthrough instructions.

### Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start services with Docker:
   ```bash
   docker-compose up
   ```

3. Run the start script:
   ```bash
   # Windows
   start.bat
   
   # Linux/Mac
   ./start.sh
   ```

## Project Files

- `docker-compose.yml` - Docker service configuration
- `package.json` - Node.js dependencies
- `build.gradle.kts` - Gradle build configuration
- `settings.gradle.kts` - Gradle settings
- `local.properties` - Local development properties
- `walkthrough.md` - Detailed project documentation
